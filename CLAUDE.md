# Diese Library: HomematicExtended  

- Diese Library dient zur Ergänzung der in Symcon vorhandenen Anbindung von Homematic-Geräten, an die Software IP-Symcon. Sie stellt die notwendigen Module und Funktionen bereit, um spezielle Homematic-Geräte in IP-Symcon zu integrieren und zu steuern.
- Die Library ist so konzipiert, dass sie leicht erweiterbar ist, um fehlende Abschnitte bei der Erweiterung der Homematic API zu ergänzen. Dabei ist der Datenfluss des Homematic-Sockets zu berücksichtigen, um die Kommunikation zwischen den Geräten und IP-Symcon zu gewährleisten.
